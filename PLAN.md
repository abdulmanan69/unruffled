### What developers repeatedly reimplement

1. **Async button.** `keywords:async-button` = 3 npm packages; the only trafficked one (`react-async-button`, 91,691/wk) was last published **2017-07-31 with 0 dependents**. shadcn#3117, #6734, shadcn-vue#282, base-ui#5133 all request it; none shipped. `disabled={isPending}` provably leaks because RHF's `handleSubmit` runs async validation _before_ your handler, so both clicks of a double-click pass validation before either mutates.
2. **Confirm with a lifecycle.** Combined gap-filler traffic (material-ui-confirm 141k, react-confirm-alert 76k w/ last commit 2022, react-confirm 63k, overlay-kit 73k) is **~0.6% of `@radix-ui/react-alert-dialog`'s 59.2M/wk**. MUI #24759 open since 2021-02-03.
3. **Undo window.** The only correct implementation in the ecosystem is react-admin's `mutationMode: 'undoable'` (208k/wk, framework-locked). `use-undo` = 16,084/wk vs Sonner's 63.5M. `react-undo-toast`, `use-undo-toast`, `use-undo-stack` are **unpublished names**. The r/reactjs thread (37 pts, 33 comments) contains zero library answers — every reply is a backend soft-delete pattern.
4. **Server errors → fields.** `setError` sets one error per call, so everyone writes the loop. TanStack/form#2188 (26 👍) is the **highest-upvoted open request** in the entire research sweep; discussion #2107 opens by linking five prior threads and its working answer doesn't typecheck.
5. **Cross-page selection.** TanStack Table documents it: with `manualPagination`, `getSelectedRowModel` only returns the current page. The shipped workaround in #4781 is a user saying "we fetch all ids and set selection manually… we'll see when it breaks down."

## 2. Library name

**`unruffled`** — npm scope **`@unruffled`**, GitHub org **`unruffled-dev`**.

Recon-verified FREE: `unruffled` 404 on npm with all moniker-rule variants clear (`un-ruffled`, `un_ruffled`, `unruffled-ui`), scope `@unruffled` FREE, no trademark or JS-tooling collision. 9 chars, 3 syllables, unambiguous spelling and pronunciation; an **adjective describing how the UI behaves**, which avoids React-vocabulary collisions (`composure`→compose, `statecraft`→state management, `nextbeat`→Next.js). The bare GitHub user is taken and dormant, hence the `-dev` org.

**Backups:** `unflappable` / `@unflappable` (npm + scope + `unflappable-ui` and `unflappablejs` all FREE; literally "not perturbed by setbacks"; costs 11 chars/4 syllables at every import). `sangfroid` / `@sangfroid` (npm + scope FREE; best meaning-per-character, but English speakers misspell French loanwords, which taxes word-of-mouth).

Rejected: `poise` (npm taken, scope reserved, Chef framework owns the GitHub org, Kimberly-Clark owns USPTO #74058158 and page one of search). `deftui`/`atomicui`/`reflexui` — all return 404 but are **unpublishable** via the npm punctuation rule (`deft-ui@0.1.8`, `atomic-ui@1.0.5`, `reflex-ui@0.1.0` block them; the 403 lands at PUT, invisible to `--dry-run`). `softfail` is free and precise and stays in the API (`classify`, `kind: 'soft'`) — "fail" in a brand sells an admission.

## 3. Core concept & USP

An **action** is a declared object, not a boolean you re-derive at every call site: you specify the async function once together with its guard, pending-visibility policy, error taxonomy, undo window, focus policy and announcement strings, and get back an inspectable plain-data machine. A ~4kB zero-dependency vanilla-TS core holds every machine with all impurity behind seven named ports (clock, scheduler, storage, navigation, doc, announcer, transport), so timing is deterministic in tests and a non-React adapter is a 6-interface job. A dev-only diagnostics bus subscribes to those same machines and console-warns with stable codes when the wiring is unsafe — destructive action with no undo path, 400ms of pending with no live region mounted, an undo window with no navigation flush.

**USP:** The async half of your UI — guard, pending, confirm, undo, rollback, retry, partial failure, empty-vs-filtered-empty, screen-reader announcements — as a ~7kB headless machine layer that composes over the Button, Dialog, Toast and Table you already own, and that tells you in the console which call sites are still wrong.

## 4. Why install this instead of shadcn/ui

- **shadcn gives you markup; this gives you the eleven seconds after the click.** Its own changelog called the Oct 2025 batch "the boring stuff we rebuild over and over" and shipped Spinner, Empty, Field, Item — all layout, zero behavior. You install both.
- **The documented shadcn answer to pending state is a manual spacing contract.** "Render a `<Spinner />` inside the button… remember to add `data-icon="inline-start"`" — at every call site, and it still doesn't disable the button, hold its width, set `aria-busy`, or stop the second click.
- **Your Undo button is a lie and nothing in that stack can fix it.** Sonner's action has no timer, TanStack Query cannot cancel a sent mutation, and there is no delayed-mutation primitive — so "Undo" dismisses a toast while the DELETE already landed.
- **`aria-live` appears 0 times in all 61 shadcn components and all 316 of its doc pages.** "Saved", "Deleted", "Failed — retry" are silent to assistive tech in a stack built on an accessibility library whose one live-region primitive is published and deliberately unexported.
- **You cannot lint your way to this and you cannot discipline your way to it.** Our diagnostics bus is the only thing in the ecosystem that reports "this destructive action has neither a confirm nor an undo path" — a recon grep found 184 reduced-motion violations across 188 components in minutes, proving the audit class is trivial and completely absent.

## 6. Architecture

```
unruffled/ (pnpm workspace, single semver train, Changesets)
├─ packages/
│  ├─ core          @unruffled/core        0 deps     ~4.0kB gz
│  ├─ react         @unruffled/react       peer react ~2.2kB gz
│  ├─ query         @unruffled/query       peer @tanstack/react-query  ~0.6kB
│  ├─ form          @unruffled/form        peer react-hook-form       ~0.6kB
│  ├─ devtools      @unruffled/devtools    dev-only, 0 prod bytes
│  ├─ eslint-plugin @unruffled/eslint-plugin
│  ├─ testing       @unruffled/testing
│  └─ intl          @unruffled/intl        interface + en, de, fr, es
├─ examples/next-shadcn-crm   (the canonical demo + e2e target)
├─ registry/                  (shadcn-compatible GLUE examples only — zero pixels)
└─ docs/                      (Next.js + llms.txt + per-page .md + MCP server)
```

**Core (vanilla TS, no DOM access, no React import).** Thirteen machine families over one ~1.2kB runtime. Machines are **inspectable plain data** — `{props, initial, context, computed, on, states, implementations:{guards, effects, actions}}` — serializable, diffable, visualizable, and unit-testable in Node. Everything impure is an injected **port**: `clock` (timers → undo windows and 150ms thresholds test with a fake clock instead of flaking), `scheduler` (microtask/idle), `storage`, `navigation` (flush-on-leave: `pagehide`/`visibilitychange`/`sendBeacon`), `doc` (**ownerDocument/root scoping** — this is the Radix shadow-DOM bug class, open 3+ years across #2606/#1772/#3353/#1721, and our live region, focus restore and global listeners all have the same hazard), `announcer`, `transport` (abortable request wrapper), `logger` (the diagnostics sink). No port is required; each has a DOM default supplied by the adapter and a deterministic default supplied by `@unruffled/testing`.

**Adapter contract — six interfaces, published as a versioned document.** `Bindable<T>` (controlled+uncontrolled get/set/subscribe), `Refs<T>` (non-reactive mutable — where the synchronous single-flight guard lives), `Track(deps, effect)`, `useMachine(lifecycle)`, `createNormalizer(propShape)`, plus the port bundle. **Reactivity lives in the adapter, never in a framework-neutral store** — Zag shipped a shared store, measured it (Dialog mount 688.9ms → 135.5ms, Tooltip −82%, Avatar update 890ms → 1.9ms) and tore it out in v1. A future `@unruffled/vue` / `svelte` / `vanilla` implements those six and nothing else; the contract exists **so the port is mechanical later, and we ship zero of them in 1.x and promise none** (`@ark-ui/svelte` sitting fifteen minors behind react is how a multi-framework promise dies in public).

**React adapter.** `useSyncExternalStore`, peer `react: ^18 || ^19` — **never a pinned minor** (Mantine 9's `^19.2.0` excluded React 18 _and_ 19.0/19.1 at a non-major boundary for zero gain). An optional `@unruffled/react/r19` entry bridges `useOptimistic`/`useActionState`/`useFormStatus`/`useTransition` when present and no-ops otherwise. Hooks + prop-getters only; no component file exports a non-component (shadcn#7736 breaks `react-refresh/only-export-components` for every consumer).

**Diagnostics bus — the product wedge.** Every machine emits a transition stream. `@unruffled/devtools` subscribes, reachable only through a `"development"` export condition and guarded by `process.env.NODE_ENV !== 'production'`, so production ships **zero bytes**. Stable codes, call-site attribution, docs URL, individually suppressible, and each fires when the wiring is **wrong** (Motion's reduced-motion warning fires backwards; we don't repeat that): `UX1001` destructive intent with neither confirm nor undo path · `UX1002` unkeyed action mutating a resource already in flight · `UX1003` pending exceeded 400ms with no `<Announcer>` mounted · `UX1004` unhandled rejection with no enclosing failure classifier · `UX1005` `disabled` used while a Gate reason exists · `UX1006` data state rendered with a non-empty filter signature and no `emptyFiltered` branch · `UX1007` undo window scheduled with no navigation flush port · `UX1008` dirty form with no guard (and no overlay intercept) · `UX1009` ConfirmHost mounted outside your providers. `@unruffled/eslint-plugin` covers the statically visible subset; `expectExhaustive()` in `@unruffled/testing` is the test-time twin. All three read **one rule table**.

**Exports map / tree-shaking.** `"sideEffects": false`, ESM-only (CJS consumers stay on a `/cjs` compat entry, react-error-boundary's precedent), per-primitive subpaths (`@unruffled/react/action`, `/undo`, `/selection`) _plus_ a shaking barrel so the barrel is the default and the subpaths are a guarantee rather than a workaround. Conditions: `development` → devtools-wired build, `production`/`default` → stripped, `types` first. `publint` + `arethetypeswrong` + `size-limit` gate every publish.

## 7. Technology choices & dependency budget

| Choice                                                      | Why                                                                                                                                                                                                   |
| ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| TypeScript 5.9, `strict` + `exactOptionalPropertyTypes`     | The type-level guarantees (recovery action required for `filtered`, descriptor-derived counts) are half the product                                                                                   |
| `tsdown` (rolldown) for builds                              | Fast, emits clean ESM + d.ts, handles the conditions map without config archaeology                                                                                                                   |
| Vitest + fake timers via the `clock` port                   | Timed behavior must be deterministic; this is why the port exists                                                                                                                                     |
| Testing Library + `@unruffled/testing` simulators           | Advance past a pending threshold, settle, assert exactly one announcement, assert the second click was swallowed, assert pagehide flushed. `@react-aria/test-utils` proves consumers adopt simulators |
| Playwright on `examples/next-shadcn-crm` only               | One real app, real SR smoke checks. No `FRAMEWORK`-matrix harness until a second adapter exists                                                                                                       |
| Biome internally; ESLint only as a shipped plugin           | Zero internal lint deps; consumers get the plugin on their existing ESLint                                                                                                                            |
| Changesets + pnpm workspaces                                | One semver train, **1.0 ships as 1.0** — no indefinite 0.x on the package people import (@floating-ui/react: 84 0.x versions over 4 years)                                                            |
| `size-limit` in CI **and** at `prepack`, with leak canaries | Motion's own bundle drifted +10% over 8 months unnoticed with 6 of 9 budgets breached                                                                                                                 |

No Zod (ship types + a 30-line validator), no clsx/tailwind-merge (we emit no classes), no Floating UI (we position nothing), no Motion (one rAF loop shared across all live countdowns). **MIT** — the tour category is the natural experiment: AGPL Shepherd (403k/wk) and intro.js (221k/wk) lose 7–12× to MIT driver.js (2.70M/wk) despite better maintenance.

## 8. Design system

**We ship zero CSS. There is no `@unruffled/css`.** The design system is a _contract_, not a stylesheet — which is also why dark mode is free and why we are never compared to Radix Themes (813kB non-tree-shakeable `styles.css` for a layer that found 1.3% of its own primitives' audience).

**Token categories — three, all behavioral.**

1. **State attributes** (discrete, for selectors): `data-pending`, `data-settling`, `data-state="cold|revalidating|empty|empty-filtered|denied|error|ready"`, `data-reason="first-run|filtered|search-miss|denied|load-failed"`, `data-row-state="pending|failed|inserting|removing"`, `data-blocked-reason="forbidden|pending|invalid"`, `data-attempt`, plus `aria-busy`/`aria-disabled`/`aria-describedby` which are semantics, not styling.
2. **Continuous custom properties** (written by the machine, read by CSS): `--u-undo-remaining` (0→1), `--u-bulk-progress`, `--u-retry-after`.
3. **Timing defaults** (read by the machine, settable in CSS _or_ config): `--u-pending-delay: 150ms`, `--u-pending-min: 400ms`, `--u-undo-window: 6000ms`.

**Naming convention.** Attributes `data-*` kebab-case mirroring Radix's `data-state` convention so existing Tailwind `data-[pending]:` variants and shadcn's `data-slot` idiom keep working unchanged. Custom properties `--u-<domain>-<name>`, single prefix, never nested, never private — Mantine's own FAQ bans consumers from touching its private variables and ours are public API by construction.

**Theming mechanism.** Two override layers, both non-forking: (a) **CSS** — redefine `--u-*` at `:root` or any ancestor; cascade handles scoping, so a dense table can set `--u-pending-delay: 0ms` for one region. (b) **Config** — `<UnruffledProvider defaults={{pending:{delay:0,min:300}, undo:{window:8000}, classify: myTaxonomy, announce: myStrings}}>`, merged per-call-site by the machine. Colors, radius and typography are **not ours** — we emit no visual, so overriding them means editing your own Button, which you already own.

**Dark mode.** Nothing to do. We never emit a color, a shadow, a radius or a font. The countdown ring on an undo toast is one CSS animation driven by `--u-undo-remaining`, and it inherits `currentColor`.

**Motion.** `prefers-reduced-motion` is respected **by default** with an explicit opt-out — the inverse of Motion's shipped `reducedMotion: "never"`, which 0 of 188 audited registry components ever discovered they needed to override. The read is reactive via `useSyncExternalStore` + `matchMedia` (Motion's own `useReducedMotion` is a `useState` snapshot with an in-source TODO admitting it). Under reduction our single rAF countdown loop stops and the affordance degrades to a text countdown, which stays accurate.

## 11. Risks

| Risk                                                                                                                                                                         | Mitigation                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **"That's just a useState and a try/catch"** — the dismissal that kills every library in this space                                                                          | Lead with diagnostics, never with primitives. The install pitch is "it tells you your delete has no undo path and your 2-second save is silent to screen readers," which creates demand instead of assuming it. Every doc page opens with the failing hand-rolled version and the specific edge case it loses — unmount mid-window, pagehide before flush, both clicks passing RHF validation                                                                                                            |
| **Perception as "another shadcn/Radix/Mantine"** — fatal, because the saturated tiers are defended by 10–100× distribution                                                   | Ship zero pixels, zero CSS, zero widgets, forever. README line one: "unruffled renders nothing." Publish the shadcn registry with glue examples only, reaching the 42.4M/mo CLI channel while owning nothing — and refuse the inevitable "please also ship a styled `<LoadingButton>`" issue permanently (MUI 6.4, Mantine, Chakra and HeroUI all absorbed `loading` into their own Buttons; a styled competitor is dead on arrival, a headless hook serves all four plus shadcn)                        |
| **Scope creep via four defensible-looking adjacencies** — tour lifecycle, async combobox, skeleton auto-sizing, offline mutation queue — each real, each a different library | Hard-cut all four and write the refusal into CONTRIBUTING with the evidence: 279 tour packages with two healthy MIT leaders; combobox is the most saturated surface in React; 343 skeleton packages with a dead leader and `animate-pulse` free; a durable ordered conflict-aware write queue is a persistence project and Query already pauses offline mutations. We ship an offline _indicator_ and `classify`, never a queue                                                                          |
| **Upstream churn across integration peers** — eight integrations is eight APIs tracked forever; TanStack Query alone shipped 425 v5 versions                                 | 1.0 ships exactly two integrations (Query 82.8M/wk, RHF 70.3M/wk). SWR, TanStack Form, TanStack Table, both routers and the toast bindings stay as **documented ~15-line recipes**, not packages. Every integration lives behind the transport/port interface, so a breaking upstream change is one adapter file, never core                                                                                                                                                                             |
| **Timing bugs in our own machines** — a library whose entire value is correct timing failing at timing is unrecoverable reputationally                                       | The `clock` port makes every threshold, window and backoff deterministic in unit tests — no `setTimeout` in a test anywhere. `<Chaos>` forces the two unreproducible states (`partial` with a chosen failure set, `rateLimited`) on demand. The `doc` port closes the Radix shadow-DOM/ownerDocument class before 1.0, not after. Playwright covers the three failure modes that only exist in a real browser: pagehide flush, route-change flush, and a live-region announcement actually reaching NVDA |
